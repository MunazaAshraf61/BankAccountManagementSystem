# Bank Account Management System

## About the Project
This is a simple Bank Account Management System developed using Python. The project allows users to create a bank account, deposit and withdraw money, check their balance, and view their transaction history.

It is a menu-driven program that uses object-oriented programming concepts. Account details and transaction records are stored in CSV files so that the data remains available even after the program is closed.

## Features
- Create a new bank account
- Deposit money into an account
- Withdraw money from an account
- Check the available balance
- Display account details
- View transaction history
- Save account information using CSV files
- Handle invalid inputs and file-related errors

## Concepts Used
- **Classes and Objects:** To organize the program into different classes.
- **Inheritance:** The `SavingsAccount` class inherits from the `BankAccount` class.
- **Abstraction:** An abstract base class is created using Python's `abc` module.
- **File Handling:** CSV files are used to store account details and transaction records.
- **Exception Handling:** Used to handle invalid amounts and file errors.

## Files in the Project
- `bank_management.py` – Contains the main Python code.
- `accounts.csv` – Stores account numbers, account holder names, and balances.
- `transactions.csv` – Stores transaction details, including dates, amounts, and balances.
- Output_01.png,Output_02.Png,Output_03.Png,Output_04.Png – screenshot showing the program running.
- README.md – provides information about the project.

The CSV files are created automatically when required by the program.
